Hook · activation of prior knowledge
Sound familiar?
"Has anyone ever had five analysts writing SQL in five different tools - and the finance team and data team producing completely different revenue numbers?"
revenue_v2_final.sql orders_cleaned_new.sql customers_REAL.sql join_maybe.sql
Nobody knows which query is the source of truth. Nobody tested it. Nobody documented it. And when something breaks, nobody knows where to start.

dbt fixes this. Today you will understand exactly how.
Core concept
What is dbt?
📄

A model is just a SELECT

Every dbt model is a .sql file with a SELECT statement. dbt compiles it and builds a table or view in your warehouse automatically.

models/stg_orders.sql
🔗

ref() is how models connect

Instead of hardcoding table names, you use ref('model_name'). dbt figures out the right order to run everything automatically.

from {{ ref('stg_orders') }}
🗺️

The DAG shows dependencies

A visual map of how your models connect. Built automatically from your ref() calls. Shows you the order models will run.

dbt docs generate
▶️

dbt run builds everything

One command. dbt compiles all your SQL, checks the dependencies, and runs everything in the right order against your warehouse.

dbt run
Live demo
dbt Cloud IDE walkthrough
Watch, then you will describe what you saw.
dbt Cloud IDE - jaffle_shop project
-- models/staging/stg_orders.sql
select order_id, customer_id, order_total, order_date
from {{ source('raw', 'orders') }}
 
-- models/marts/revenue_by_customer.sql
select customer_id,
  sum(order_total) as total_revenue,
  count(order_id) as order_count
from {{ ref('stg_orders') }}
group by customer_id;
 
$ dbt run
OK created view model staging.stg_orders
OK created table model marts.revenue_by_customer

Check for understanding
Quick check
Pick the best answer - no pressure.
In a dbt model, you write from {{ ref('stg_orders') }} instead of from raw.orders. What is the main benefit?
A
It makes the SQL run faster against the warehouse
B
dbt knows the dependency and automatically runs stg_orders first
C
It prevents other analysts from editing the stg_orders model
D
It connects the model directly to the source database
✓ B is correct. ref() tells dbt that this model depends on stg_orders. dbt uses that to build the DAG and ensure stg_orders runs first. Without ref(), dbt cannot determine the order.
